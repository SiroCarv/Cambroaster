# Cambroaster

Sistema web y móvil de pedidos, cocina y caja para pollerías y negocios de comida rápida. Reemplaza el papel por un registro digital ordenado: toma los pedidos, calcula los totales, controla la caja y muestra cuánto se vende y cuánto se gasta.

Demostración en línea: https://cambroaster.vercel.app

Cuenta de demostración: usuario `roxana`, contraseña `rrj2026`.

## Qué permite hacer

- Tomar pedidos por mostrador, WhatsApp o delivery, con platos, porciones extra y comanda.
- Calcular la tarifa de delivery por barrio, con recargo por lluvia.
- Ver en cocina los pedidos en orden de llegada y avisar cuando el arroz se agota.
- Ver los cobros del día, hacer el arqueo y cerrar la caja.
- Registrar las compras de bebidas al proveedor.
- Consultar reportes: ventas del día y por período, platos más vendidos, horas de mayor demanda e historial de pedidos.
- Cambiar platos, precios, porciones extra y tarifas de delivery desde el menú.

## Tecnologías

- Sistema web: PHP con Laravel, bajo el patrón MVC.
- Base de datos: MySQL, administrada con phpMyAdmin.
- Entorno de desarrollo: Laragon (Apache).
- Aplicación móvil: Kotlin, nativa para Android.
- Control de versiones: Git y GitHub.
- Gestión de tareas: Jira (tablero Kanban).
- Publicación de la demostración: Vercel.

## Demostración en línea

La demostración publicada en Vercel muestra las pantallas principales del sistema en una sola página y guarda los datos en el navegador del dispositivo.
